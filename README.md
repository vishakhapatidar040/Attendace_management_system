# 📋 Smart Attendance Management System

`status: active` `python: 3.9+` `flask: backend` `license: MIT`

> A simple, fast web app to manage student attendance — add students, mark daily attendance, and track attendance percentage automatically. ✨

![Animated project overview](animated_banner.svg)

## 🎯 About the Project

The **Smart Attendance Management System** is a Flask-based web app built to replace manual attendance registers. Admins can log in, manage a student list, mark attendance by date, and instantly view attendance percentage reports per student. 🚀

## ✨ Key Features

- 🔒 **Admin login** with secure password hashing
- 👥 **Student management** — add or remove students
- 📝 **Daily attendance marking** — editable by date
- 📊 **Auto-generated reports** with attendance percentage
- 📆 **Per-student attendance history**
