## 📋 About the Project

**Smart Attendance Management System** is a Flask-based web application that streamlines student attendance for schools and institutes. It replaces manual registers with a clean digital workflow, giving administrators secure access to student records, daily attendance marking, and instant percentage reports per student.

The result is a faster, more reliable attendance process with less manual work and fewer reporting mistakes.

## ✨ Key Features

- 🔒 **Secure admin login** with password hashing
- 👥 **Student management** to add, edit, or remove students
- 📝 **Daily attendance marking** by date
- 📊 **Auto-generated attendance percentage reports**
- 📆 **Per-student attendance history** for quick review

## 🚀 Getting Started

1. **Clone the repository**
```bash
git clone https://github.com/your-username/Attendance_management_system.git
cd Attendance_management_system
```

2. **Create and activate a virtual environment**
```cmd
python -m venv venv
venv\Scripts\activate.bat
```

3. **Install dependencies**
```cmd
pip install -r requirements.txt
```

4. **Run the application**
```cmd
python app.py
```

5. **Open the app in your browser**

	 Visit `http://127.0.0.1:5000` after the server starts.
