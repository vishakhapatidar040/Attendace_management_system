## 📋 About the Project

**Smart Attendance Management System** is a Flask-based web application designed to streamline attendance tracking for schools and institutions. It replaces manual, paper-based registers with a fast, reliable digital system — allowing administrators to manage students, record daily attendance, and generate accurate percentage reports in real time.

## ✨ Key Features

- 🔒 **Secure admin login** with password hashing
- 👥 **Student management** — add or remove students easily
- 📝 **Daily attendance marking** — editable by date
- 📊 **Auto-generated attendance percentage reports**
- 📆 **Per-student attendance history**

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| Python | Core programming language |
| Flask | Backend web framework |
| Flask-SQLAlchemy | Database ORM |
| SQLite | Database |
| HTML / CSS / JS | Frontend |

## 🚀 Getting Started

1. **Clone the repository**
```bash
	git clone https://github.com/vishakhapatidar040/Attendance_management_system.git
	cd Attendance_management_system
```

2. **Create and activate a virtual environment**
```bash
	python -m venv venv
	venv\Scripts\Activate.ps1      # Windows PowerShell
```

3. **Install dependencies**
```bash
	pip install -r requirements.txt
```

4. **Run the application**
```bash
	python app.py
```

5. **Open in your browser**
